# 磷酸化中心化契约

## 范围

本契约适用于 `SCP682main-1` 的训练、内部验证、伪外部锚定评价和外部队列推理。

## 数据变换

每个样本的真实磷酸化标签仅利用该样本可观测位点计算中位数。缺失值不参与中位数计算，也不参与损失和指标。

每个样本的基线预测独立使用可用基线位点计算中位数。该处理不依赖真实磷酸化标签，可用于外部推理。

## 模型约束

图残差和普通残差相加后，对每个样本投影为零中位数。该约束防止残差头通过整体抬高或降低全部位点拟合质谱偏移。

## 报告规则

- 正式 Spearman、均方误差和余弦均在中心化磷酸化尺度计算。
- 原始尺度预测和原始尺度评价只作为诊断文件。
- 每次训练保存样本中心化偏移表、输入图摘要、检查点和逐位点指标表。
