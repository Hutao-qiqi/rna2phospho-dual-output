# 最终架构审计（2026-07-20）

## 审计结论

当前实现与约定的“总蛋白锚定的轴向动态通路图磷酸化残差模型”一致，可以进入正式训练。总蛋白预测器不属于本模型，磷酸化梯度不会进入总蛋白预测。

## 正式数据契约

- 916例训练样本：总蛋白采用五折交叉拟合预测；研究校准在每个审计折内重新拟合。
- 229例选择验证样本：总蛋白预测和研究校准只使用916例训练样本拟合。
- 286例封存样本：不进入总蛋白开发预测矩阵，磷酸化标签不读取。
- 总蛋白预测矩阵：1,145 × 11,311，全部为有限值。
- RNA：19,938个基因。
- 磷酸化：18,592个位点。

上游总蛋白分支的超参数没有在每个校准审计折内重新选择。该事实已写入来源清单。每个训练样本的上游基础预测和研究校准均不使用本样本总蛋白标签直接拟合，磷酸化标签从未参与；若论文需要声明“所有超参数完全嵌套交叉拟合”，仍需补做上游全嵌套训练。

## 最终数据流

1. 每个样本的RNA在固定19,938基因轴上做样本内秩变换。
2. 已完成预测的11,311个总蛋白按916例训练集参数标准化，只作为停止梯度输入。
3. RNA和预测总蛋白分别按128条通路池化，形成样本—通路状态。
4. 通路轴注意力只允许具有先验关系的通路交换信息；全局状态与所有通路连接。
5. 通用RNA近邻图只提供候选邻居，每条通路、每个样本和每个注意力头重新学习边权。
6. 每个位点查询由位点身份、母蛋白身份和动态丰度、激酶集合、相关通路状态组成。
7. 位点只读取先验关联通路；母蛋白、激酶和通路三类消息采用归一化门控。
8. 输出为训练折内拟合的位点母蛋白校准基线，加位点级收缩后的零中位数残差。

## 生物先验覆盖

真实输入的128通路审计结果：

- 18,592个位点全部具有母蛋白映射；
- 13,210个位点具有至少一条具体通路，剩余位点读取固定全局通路；
- 3,921个位点具有激酶先验；
- 激酶词表包含288个激酶；
- 激酶先验合并OmniPath/KSTAR格式文件、CoPHEE-KSA预测和已有位点先验，重复边按集合合并。

## 中位数中心化与母蛋白基线

每个位点只在916例训练样本内拟合：

\[
B_{is}=a_s+\beta_s\widehat P_{i,\operatorname{parent}(s)}.
\]

磷酸化目标和母蛋白基线分别执行样本内中位数中心化。神经网络学习中心化磷酸化减中心化母蛋白基线的残差。最终残差再次在固定18,592位点轴上投影到零中位数空间。位点级收缩参数受到向零正则，没有样本级整体抬升门。

## 图推理边界

- 训练样本的候选图排除自身节点。
- 229例验证样本只连接916例训练参考库。
- 外部样本只连接检查点内保存的训练参考库。
- 外部样本之间不连边，参考节点不包含真实磷酸化值。

## 本轮修正

1. 新增总蛋白锚点打包程序，输出预测矩阵、固定划分、逐样本来源和散列审计。
2. 修正验证分块时二维邻居矩阵沿错误维度切片的问题。
3. 扩展激酶先验读取，支持 `kinase_gene/substrate_gene/substrate_site` 和 `parent_gene/site`。
4. 修正逐位点皮尔森损失在零预测方差时产生非有限梯度的问题。
5. 梯度裁剪启用非有限梯度保护。
6. A800默认使用32位浮点；混合精度保留为显式选项。
7. 新增只做完整输入和先验审计、不启动训练的入口选项。

## 验证结果

- 24项测试全部通过。
- 合成GPU前向、反向和停止梯度检查通过。
- 真实数据两轮短训练完成，包含229例分块验证和检查点保存。
- 短训练只启用8条通路，第二轮逐位点斯皮尔曼中位数为0.336855，仅用于验证链路。
- 完整128通路输入审计通过，封存磷酸化行未读取。

## 正式训练设置

- 精度：32位浮点；
- 通路数：128；
- 隐藏维度：64；
- 注意力头：4；
- 轴向层：2；
- 样本候选邻居：16；
- 位点分块：512；
- 检查点指标：229例逐位点斯皮尔曼中位数。

两张A800适合并行运行主模型和消融实验。当前训练入口单进程使用一张GPU，不需要为了单次训练引入跨卡通信。
