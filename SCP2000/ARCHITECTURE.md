# 模型架构

令RNA为X，RNA预测蛋白为P。分别使用训练参数完成缺失填补、中心化和尺度变换，再以RNA的256维、蛋白的128维投影拼接为384维特征，并使用训练特征均值与尺度标准化。

多输出岭回归以惩罚1000预测128维标准化PTM坐标，随后还原坐标尺度。坐标16、19、24、31、42、49、56、59使用独立岭回归：384维公共特征额外拼接该坐标选择的16个RNA特征及8个预测蛋白特征，惩罚仍为1000。编号从1开始。

对于患者i和位点s，基础重构为：

`Y_hat[i,s] = B[study(i),s] + beta[s] * (P[i,parent(s)] - P_center[study(i),parent(s)]) + site_mean[s] + Z_hat[i,:] @ V[:,s]`

V为冻结128×18,592位点基底，beta为母蛋白直接效应系数。独立基础推理入口使用训练集全局位点均值作为B；默认采用训练集全局预测蛋白中心。提供研究元数据时，蛋白中心改为输入患者按研究分组的预测蛋白均值。内部开发评价使用训练患者估计的研究背景，目标域PT7使用校准患者估计的研究背景。基础推理的输入P来自RNA预测。

PT7在目标队列校准集内学习128维坐标的低秩修正：岭惩罚10、秩24，再进行位点斜率收缩，参数gamma=0.10、lambda=1、kappa=100。完整实现位于`03_code/model_validation/scp682_v2_m22_study_centered_evaluation/02_rerun_external_pt7_centered.py`。

患者谱堆叠结合M2.2与S1各自适配后的输出，逐位点岭惩罚30，向基础输出收缩比例0.10。S1源代码和输出堆叠代码位于`03_code/model_validation/scp682_v2_m22_phosphosct/`。

基础模型、目标域适配和患者谱堆叠分别调用对应入口；核心NPZ保存基础模型参数。
